# Midnight Marquee

A streaming platform/content catalog app built with React. Displays a curated catalog of free movies and series (YouTube-hosted) with a Netflix-style UI.

## Features

- Netflix/streaming-service inspired dark UI
- Sidebar navigation (Home, Movies, Series, Browse, My List)
- Full-text search with keyboard shortcut (/)
- Browse page with type filtering (movies/series)
- Spotlight/featured content section
- Movie/series detail modal with cast, description, genre
- Embedded YouTube video player on Watch page
- "My List" for saving favorites (persisted)
- Scroll-to-top on route change
- Escape key to close modals
- 50+ curated films/series with metadata
- Page transition animations
- Responsive layout
- React context for global state

## Tech Stack

- React 18
- React Router v6
- Vite 5
- React Context for state management

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Launch

Double-click `Launch Midnight Marquee.bat` for quick launch.

## Content Catalog

Includes 50+ free films and series with metadata:
- Title, year, type (movie/series)
- Maturity rating and runtime
- Genres and director
- Cast information
- YouTube video IDs for streaming
